2. RESEARCH GAP

No existing framework (PentestGPT, xOffense, VulnBot) includes an architecturally isolated NLU preprocessing layer with formal validation guarantees.

3. RESEARCH PROBLEM

Penetration testing workflows remain heavily manual and time-consuming, while global attack surfaces expand exponentially, creating a dangerous execution gap for security teams.

01

Raw commands reach planners unchecked

Hallucination, semantic ambiguity and prompt injection.

02

Unreliable command generation

Static templates and unrestricted LLM output produce inaccurate, unsafe commands.

03

Failures stop the pipeline

A failed command waits for a human operator.

04

Too many false alarms

CVSS-only scoring buries the findings that matter.

4. RESEARCH OBJECTIVES

Improve the reliability and safety of AI in offensive-security workflows, from natural-language intent to prioritized findings.
01 Block hallucinated or ambiguous output before execution through structured outputs and deterministic validation.
02 Ground command generation in real Kali documentation and validate every command before it runs.
03 Execute safely in Docker sandboxes and recover from terminal errors without human help.
04 Predict real-world exploitability, score risk in context and reduce false positives.
Schema validity ≥ 98%
Recovery success ≥ 80%
Recovery time < 10 s
Zero dangerous commands executed
